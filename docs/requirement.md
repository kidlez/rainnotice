# 雨声提醒 - 需求开发文档

## 1. 项目概述

### 1.1 项目背景
在日常生活中，人们经常因为专注于工作或学习而忘记一些重要的时间节点，如吃饭、喝水、运动等。同时，天气变化也会对出行造成影响，但往往等到下雨时才被发现。本项目旨在提供一种有趣的、带有关怀感的提醒工具，帮助用户更好地管理日常事务，同时不错过任何天气变化。

### 1.2 项目目标
- 提供可自定义的时间节点提醒功能
- 集成天气检查和降雨预警
- 通过语音和通知两种方式进行播报
- 支持iOS和Windows双平台

### 1.3 目标用户
- 独自在外工作的上班族
- 需要提醒关注健康的学生
- 希望有条理管理日常的用户

## 2. 功能需求

### 2.1 天气模块

#### 2.1.1 城市管理
- 支持自动定位获取当前城市
- 支持手动搜索和添加城市
- 支持管理多个城市（至少3个）
- 城市数据：名称、城市代码

#### 2.1.2 天气数据获取
- 接入和风天气免费API
- 获取实时天气数据
- 获取2小时分钟级降水预报
- 数据刷新间隔：30分钟

#### 2.1.3 降雨检测
- 检测当前是否正在下雨
- 检测2小时内是否有雨
- 支持设置预警提前量（默认30分钟）
- 降雨提示触发时推送通知+语音播报

#### 2.1.4 API Key配置
- 用户自行填写API Key
- 提供和风天气申请指引
- Key本地安全存储

### 2.2 提醒模块

#### 2.2.1 预设提醒模板
提供以下默认提醒：

| 场景 | 默认时间 | 毒鸡汤 | 暖心语 |
|------|----------|--------|--------|
| 吃饭 | 12:00 | 再忙也要吃饭，身体是革命的本钱 | 辛苦啦，先吃点东西吧 |
| 喝水 | 10:00 | 水是生命之源，别把自己渴死 | 多喝点水，对身体好哦 |
| 运动(上午) | 14:00 | 久坐伤身，起来动动 | 起来活动一下吧 |
| 运动(下午) | 18:00 | 再不运动夏天就过去了 | 运动一下吧~ |
| 休息 | 13:00 | 休息是为了走更远的路 | 适当休息一下~ |

#### 2.2.2 自定义提醒
- 自定义场景名称
- 自定义提醒时间
- 自定义慰问语（可选）
- 可选启用/禁用

#### 2.2.3 提醒管理
- 新增提醒
- 编辑提醒
- 删除提醒
- 批量开启/关闭
- 提醒列表按时间排序

### 2.3 通知与播报

#### 2.3.1 系统通知
- 本地推送通知
- 通知标题：场景名称
- 通知内容：对应慰问语
- 支持设置通知声音

#### 2.3.2 语音播报
- 调用系统TTS
- 支持中文语音
- 可调节语速（0.5x - 2.0x）
- 可单独开关语音

#### 2.3.3 播报风格
- 毒鸡汤风格：幽默、扎心
- 暖心风格：温柔、关怀
- 支持实时切换
- 雨天附加天气提醒

### 2.4 设置模块

#### 2.4.1 基础设置
- API Key配置
- 默认城市选择
- 消息风格选择

#### 2.4.2 通知设置
- 通知开关
- 语音播报开关
- 语速调节

#### 2.4.3 其他设置
- 深色模式跟随系统
- 关于页面

### 2.5 后台运行

#### 2.5.1 静默运行原则
- App平时不打扰用户，仅在提醒时间到达时弹出通知/语音
- 无弹窗、无横幅、无前台抢占
- 仅在系统通知栏出现提醒

#### 2.5.2 Windows 实现
- 最小化到系统托盘
- 关闭窗口不退出程序（需托盘右键退出）
- 后台定时唤醒检查天气和提醒
- 到时间触发系统通知 + TTS语音

#### 2.5.3 iOS 实现
- App关闭后依赖本地推送通知（提前批量注册）
- 无需后台运行，系统自动按计划弹出
- 每次打开App时检查并补注册未来24小时提醒

#### 2.5.4 天气后台更新策略
- 仅在提醒触发前5分钟拉取一次天气数据
- 非提醒时间段不调用API
- 每天最多拉取：提醒次数 + 1次首页打开刷新

## 4. 技术方案

### 4.1 技术选型

| 组件 | 技术 | 版本 |
|------|------|------|
| 框架 | Flutter | 3.x |
| 语言 | Dart | 3.x |
| 状态管理 | Riverpod | ^2.0 |
| 本地存储 | Hive | ^2.0 |
| HTTP请求 | Dio | ^5.0 |
| 本地通知 | flutter_local_notifications | ^16.0 |
| 后台任务 | workmanager | ^0.5.0 |
| TTS | flutter_tts | ^4.0 |
| 系统托盘 | system_tray (Windows) | ^2.0 |
| 定时调度 | background_fetch | ^1.0 |

### 4.2 后台运行策略

```
Windows 模式:
  启动App -> 显示主界面
  用户关闭窗口 -> 最小化到系统托盘
  托盘图标常驻 -> 定时唤醒检查提醒
  到时间 -> 系统通知 + TTS语音
  托盘右键菜单 -> 打开界面 / 退出

iOS 模式:
  启动App -> 批量注册未来24小时本地通知
  关闭App -> 系统代为管理通知推送
  到时间 -> iOS系统弹出通知横幅
  打开App -> 补注册新一天的通知
```
